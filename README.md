# Landing Método Fantasma

Landing page de alta conversión para el **Método Fantasma**.

## 📁 Estructura

- `index.html`: Punto de entrada principal para despliegue en web estática (GitHub Pages, Vercel, Netlify).
- `metodo-fantasma-landing modificada.html`: Copia del archivo original de la landing page.

## 🚀 Despliegue en GitHub Pages

1. Ve a **Settings** > **Pages** en este repositorio.
2. En **Source**, selecciona `Deploy from a branch`.
3. Selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda los cambios. Tu landing estará en línea en pocos minutos.
